## 0. 一句话概括

**只算当前可见区间** → 把它**等分成 600 片** → 每片取**片内的峰值**（min/max 里绝对值大的那个）
→ 绘制时**片内用这个高度填满**（所以是阶梯状，不是逐采样曲线）。

不做整轨预计算：长视频导入时先出画面，波形再在后台补。

## 4. 算法本体（`buildCore`，AudioPeaks.cpp:27–204）

### 第 1 步　开链路

```
avformat_open_input → avformat_find_stream_info
→ 找第一条音轨（没有就返回 false，上层显示"无音轨"）
→ avcodec_find_decoder / alloc_context3 / parameters_to_context / open2
→ swr 重采样上下文：输出 单声道 / s16 / 8000Hz
```

### 第 2 步　seek（两个坑都在这里）

```cpp
if (seekToStart) {
    // 往前多退 1 秒再 seek：音频 seek 只能落到关键位置，直接定位到 fromSec
    // 很容易丢掉开头那一段，波形左端就会缺一块
    const double back = std::max(0.0, fromSec - 1.0);
    const int64_t ts = static_cast<int64_t>(std::llround(back / streamSec));
    api.avformat_seek_file(fmt, audioIdx, INT64_MIN, ts, ts, 0);
    // 注意：seek 后必须用 avcodec_flush_buffers 清掉解码器里积压的旧帧。
    // 用"发一个空包"代替会把解码器推进 draining 状态，之后 send_packet
    // 一律返回 AVERROR_EOF，表现就是"怎么都解不出采样"。
    api.avcodec_flush_buffers(codecCtx);
}
```

### 第 3 步　投片（核心循环）

先把 `out.min` / `out.max` 各预置成 `bucketCount` 个 0，然后每来一段采样就按时间投：

```cpp
const double sampleStep = 1.0 / double(kOutSampleRate);
auto feed = [&](const int16_t *samples, int count, double startSec) -> bool {
    double t = startSec;
    for (int i = 0; i < count; ++i, t += sampleStep) {
        if (t >= toSec) return true;      // 越过区间末尾，停
        if (t < fromSec) continue;        // seek 回退多解的部分，丢掉
        const std::size_t idx =
            static_cast<std::size_t>((t - fromSec) / spanSec * double(bucketCount));
        if (idx >= bucketCount) continue;
        const int16_t v = samples[i];
        if (v < out.min[idx]) out.min[idx] = v;
        if (v > out.max[idx]) out.max[idx] = v;
    }
    return false;
};
```

外层：`av_read_frame` → 只收音轨包 → `send_packet` / `receive_frame`
→ 用 `frame->pts`（没有就用 `pkt_dts`）换算这一帧的起始秒数
→ `swr_convert` 出 8192 一块地喂给 `feed`。

### 第 4 步　冲残留（不冲末尾几片会偏小）

```cpp
if (!stop) {
    int produced = api.swr_convert(swr, &buffer, kBufferSamples, nullptr, 0);
    while (produced > 0) { ... feed(...) ... }
}
```

### 数据结构

```cpp
struct AudioPeaks {
    double fromSec, toSec;        // 覆盖区间（用来判断"这份数据是不是旧的"）
    double pointsPerSec;          // = 切片数 / 区间时长
    std::vector<int16_t> min;     // 每片最小振幅
    std::vector<int16_t> max;     // 每片最大振幅
    bool covers(double from, double to) const;   // 没覆盖 → 要重算
    int level(std::size_t i) const;              // max(|min[i]|, |max[i]|)
};
```

两个入口：

- `buildRange(api, path, from, to, slices, out, error)` —— **UI 用的就是这个**，
  `seekToStart = true`，只算可见区间；
- `build(api, path, pointsPerSec, out, error)` —— 整轨（先拿时长算片数），
  给 `media_check` 工具和兜底用。

## 5. 绘制（`TimelineWidget::drawWaveform`，303–332 行）

```cpp
const double slice = span() / double(kWaveSlices);   // 可见区间再切 600 片
for (int i = 0; i < kWaveSlices; ++i) {
    const double t0 = viewFrom_ + double(i) * slice;
    const int level = peakLevel(t0, t0 + slice);     // 片内再取一次最大
    const int h = std::max(1, lround(level / 32767.0 * halfH));
    const int x0 = lround(double(i)     * width() / kWaveSlices);
    const int x1 = lround(double(i + 1) * width() / kWaveSlices);
    p.fillRect(x0, midY - h, std::max(1, x1 - x0), 2 * h, kWaveColor);  // 上下对称的竖条
}
```

- 颜色 `kWaveColor = 0x8A8F98`（灰），以中线为轴上下对称；
- 中间再画一条 `0xCCCCCC` 的水平中线；
- 峰值还没覆盖当前可见区间时（刚导入 / 刚缩放平移），**先画占位**：
  虚线中线 + 居中文案「波形计算中…」或「无音轨」——
  这样长视频不用等波形算完就有画面。

`peakLevel(t0, t1)`（287–301 行）负责「屏幕上的一片」到「数据里的几片」的换算，
用的是 `pointsPerSec`，对不上时取区间内最大值：

```cpp
std::size_t i0 = max(0.0, (t0 - peaks_.fromSec) * pps);
std::size_t i1 = max(0.0, (t1 - peaks_.fromSec) * pps);
if (i1 <= i0) i1 = i0 + 1;
for (i = i0; i < i1; ++i) level = max(level, max(|min[i]|, |max[i]|));
```

## 6. 这套方案的好处与代价（改方案前先看这里）

**好处**

- 长视频**秒出画面**：只解可见区间那一段，1 小时片子放大到 10 秒窗口也是毫秒级；
- 内存固定：永远只有 600×2 个 `int16_t`；
- 缩放/平移后重算代价小（区间越小越快）。

**代价**

- 每次缩放/平移都要**重解一遍音频**（有 150ms 节流挡着，但连续拖动时仍会算好几次）；
- 波形是**阶梯状**的（片内取峰值填满），放大到很小的区间时会显得"块状"；
- 可见区间很大时（比如整片 1 小时铺满），600 片意味着每片 6 秒，细节全糊掉。

---

## 7. 踩过的坑（改方案时别再踩）

1. **`avcodec_flush_buffers` 是硬要求**。seek 后清解码器不能用"发一个空包"代替 ——
   那会把解码器推进 draining 状态，之后所有 `send_packet` 返回 `AVERROR_EOF`，
   现象是「怎么都解不出采样」。
2. **音频 seek 必须往前多退**（这里是 1 秒），否则开头缺一块。
3. **swr 里残留的样本要冲干净**，不然末尾几片偏小。
4. **`avformat_find_stream_info` 不能省**：很多容器不调它 `duration` 还是 0
   （`build()` 里算片数就靠它）。
5. 波形任务必须带 **两个 token**，否则换文件/连续缩放时旧结果会盖新结果。
