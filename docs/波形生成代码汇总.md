# 波形生成代码汇总

Tab1 时间轴的音频波形，按需求「先确定可见区间 → 等分 600 片 → 每片算一个高度 → 片内用该高度填满」
实现。本文把散在四个文件里的相关代码集中在一起，便于通读和修改。

> 摘录时间：2026-10-14（对应 v4.0 开发中的 Tab1 改版）。行号会随改动漂移，以函数名为准。

## 0. 调用链

```
导入视频
  └─ MainWindow::loadCutSource()            后台：探测 + 5 张缩略图 + 首帧预览
       └─（画面出来后）startCutBackgroundAssets(token)
            ├─ 关键帧表（MediaProbe::keyframeTimes）
            └─ rebuildCutWaveform(token) ──► AudioPeakBuilder::buildRange(..., 600, ...)
                                              └─ QtConcurrent 后台线程 → setPeaks()

滚轮缩放 / 拖动滑块平移
  └─ TimelineWidget::viewChanged(from, to)
       └─ MainWindow::onCutViewChanged() → scheduleTimelineAssets()  （150ms 节流）
            └─ refreshCutTimelineAssets()
                 ├─ 5 张缩略图重取
                 └─ rebuildCutWaveform()   ← 对新可见区间重新切 600 片
```

关键设计：**不做整轨预计算**。长视频导入时先出画面，波形再在后台算；
缩放/平移后可见区间变了，就只对新的区间重新解码切片。

## 1. 数据结构与接口 —— `src/ffmpeg/AudioPeaks.h`

```cpp
// ---------------------------------------------------------------------------
// 音频峰值 —— Tab1 时间轴波形层的数据源。
//
// 按需求"切片"来算：只算**当前可见区间**，把它切成 N 片（600），
// 每片得出一个波形高度（该片内的峰值，0..32767），片内用这个高度填满。
// 不做整轨预计算 —— 长视频导入时先出画面，波形再在后台算。
//
// 缩放/平移后可见区间变了，就重新对新的区间切片计算（区间小的时候很快）。
// ---------------------------------------------------------------------------

#include <algorithm>
#include <cstddef>
#include <cstdint>
#include <cstdlib>
#include <string>
#include <vector>

#include "ffmpeg/FfmpegApi.h"

namespace lr {

struct AudioPeaks {
    double fromSec = 0.0;       // 覆盖区间起点（秒）
    double toSec = 0.0;         // 覆盖区间终点（秒）
    double pointsPerSec = 0.0;  // 每秒点数（= 切片数 / 区间时长）
    std::vector<int16_t> min;   // 每片最小振幅
    std::vector<int16_t> max;   // 每片最大振幅

    bool empty() const { return min.empty(); }
    std::size_t size() const { return min.size(); }
    /// 该峰值数据覆盖的时长
    double span() const { return toSec - fromSec; }
    /// 是否完整覆盖 [from, to) —— 没覆盖就说明这份数据是旧的，需要重算
    bool covers(double from, double to) const {
        return !empty() && fromSec <= from + 1e-6 && toSec >= to - 1e-6;
    }
    /// 第 i 片的波形高度（0..32767）
    int level(std::size_t i) const {
        if (i >= min.size()) return 0;
        return std::max(std::abs(static_cast<int>(min[i])),
                        std::abs(static_cast<int>(max[i])));
    }
};

class AudioPeakBuilder {
public:
    /// 整条音轨建峰值（pointsPerSec 为每秒点数；media_check 工具与兜底用）
    static bool build(FfmpegApi &api, const std::string &path, double pointsPerSec,
                      AudioPeaks &out, std::string &error);

    /// 只算 [fromSec, toSec) 这一段的峰值，切成 slices 片
    /// （需求：可见区间切 600 片，片内用该片高度填满）
    static bool buildRange(FfmpegApi &api, const std::string &path, double fromSec,
                           double toSec, int slices, AudioPeaks &out,
                           std::string &error);
};

}  // namespace lr
```

## 2. 切片计算 —— `src/ffmpeg/AudioPeaks.cpp`

### 2.1 常量与公共入口

```cpp
constexpr int kOutSampleRate = 8000;   // 峰值只需要低频信息，8kHz 足够且快
constexpr int kBufferSamples = 8192;   // 每次 swr_convert 的输出块
```

```cpp
bool AudioPeakBuilder::build(FfmpegApi &api, const std::string &path, double pointsPerSec,
                             AudioPeaks &out, std::string &error) {
    // 先拿时长，决定片数（必须先 find_stream_info，否则很多容器 duration 还是 0）
    AVFormatContext *fmt = nullptr;
    double duration = 0.0;
    if (api.avformat_open_input(&fmt, path.c_str(), nullptr, nullptr) >= 0) {
        api.avformat_find_stream_info(fmt, nullptr);
        if (fmt->duration > 0) duration = double(fmt->duration) / double(AV_TIME_BASE);
        api.avformat_close_input(&fmt);
    }
    if (duration <= 0.0) {
        error = "读不到时长";
        return false;
    }
    const int slices = static_cast<int>(std::max(1.0, std::ceil(duration * pointsPerSec)));
    return buildCore(api, path, 0.0, duration, slices, false, out, error);
}

bool AudioPeakBuilder::buildRange(FfmpegApi &api, const std::string &path, double fromSec,
                                  double toSec, int slices, AudioPeaks &out,
                                  std::string &error) {
    if (toSec <= fromSec) return false;
    return buildCore(api, path, fromSec, toSec, slices, true, out, error);
}
```

### 2.2 `buildCore()` —— 打开 / seek / 分桶

```cpp
/// 峰值构建的核心循环：把 [fromSec, toSec) 切成 buckets 片，
/// 每片记下片内的最小/最大振幅（绘制时取该片高度填满整片）
bool buildCore(FfmpegApi &api, const std::string &path, double fromSec, double toSec,
               int buckets, bool seekToStart, AudioPeaks &out, std::string &error) {
    // …（约 60 行样板：avformat_open_input → find_stream_info → 找音轨 →
    //     avcodec_find_decoder → alloc_context3 → parameters_to_context → open2 →
    //     swr_alloc_set_opts2 重采样到 单声道/s16/8kHz → swr_init）…

    const double timeBase = av_q2d(stream->time_base);
    const double streamSec = (timeBase > 0) ? timeBase : 1.0 / 1000.0;
    if (seekToStart) {
        // 往前多退 1 秒再 seek：音频 seek 只能落到关键位置，直接定位到 fromSec
        // 很容易丢掉开头那一段，波形左端就会缺一块
        const double back = std::max(0.0, fromSec - 1.0);
        const int64_t ts = static_cast<int64_t>(std::llround(back / streamSec));
        api.avformat_seek_file(fmt, audioIdx, INT64_MIN, ts, ts, 0);
        // 注意：seek 后必须用 avcodec_flush_buffers 清掉解码器里积压的旧帧。
        // 用"发一个空包"代替会把解码器推进 draining 状态，之后 send_packet
        // 一律返回 AVERROR_EOF，表现就是"怎么都解不出采样"。
        api.avcodec_flush_buffers(codecCtx);
    }

    const double spanSec = std::max(1e-6, toSec - fromSec);
    const auto bucketCount = static_cast<std::size_t>(std::max(1, buckets));
    out.fromSec = fromSec;
    out.toSec = toSec;
    out.pointsPerSec = double(bucketCount) / spanSec;
    out.min.assign(bucketCount, 0);
    out.max.assign(bucketCount, 0);

    uint8_t *buffer = nullptr;
    int linesize = 0;
    if (api.av_samples_alloc(&buffer, &linesize, 1, kBufferSamples, AV_SAMPLE_FMT_S16, 0) < 0) {
        /* …清理并返回 false… */
    }

    // 把一段 s16 采样投进对应的片里；返回是否越过了区间末尾
    const double sampleStep = 1.0 / double(kOutSampleRate);
    auto feed = [&](const int16_t *samples, int count, double startSec) -> bool {
        double t = startSec;
        for (int i = 0; i < count; ++i, t += sampleStep) {
            if (t >= toSec) return true;
            if (t < fromSec) continue;
            const std::size_t idx =
                static_cast<std::size_t>((t - fromSec) / spanSec * double(bucketCount));
            if (idx >= bucketCount) continue;
            const int16_t v = samples[i];
            if (v < out.min[idx]) out.min[idx] = v;
            if (v > out.max[idx]) out.max[idx] = v;      // ★ 每片取片内峰值
        }
        return false;
    };

    AVPacket *packet = api.av_packet_alloc();
    AVFrame *frame = api.av_frame_alloc();
    bool stop = false;
    double writeSec = fromSec;   // 下一段待写采样的起始时间

    while (!stop && api.av_read_frame(fmt, packet) >= 0) {
        if (packet->stream_index != audioIdx) { api.av_packet_unref(packet); continue; }
        if (api.avcodec_send_packet(codecCtx, packet) < 0) { api.av_packet_unref(packet); continue; }
        api.av_packet_unref(packet);

        while (api.avcodec_receive_frame(codecCtx, frame) >= 0) {
            // 这一帧的起始时间（重采样后输出样本的时间基准）
            const int64_t pts = (frame->pts != AV_NOPTS_VALUE) ? frame->pts : frame->pkt_dts;
            const double frameSec = (pts != AV_NOPTS_VALUE) ? double(pts) * timeBase : fromSec;
            double posSec = frameSec;

            int produced = api.swr_convert(swr, &buffer, kBufferSamples,
                                           const_cast<const uint8_t **>(frame->data),
                                           frame->nb_samples);
            while (produced > 0) {
                const int16_t *samples = reinterpret_cast<int16_t *>(buffer);
                stop = feed(samples, produced, posSec);
                posSec += double(produced) * sampleStep;
                if (stop) break;
                produced = api.swr_convert(swr, &buffer, kBufferSamples, nullptr, 0);
            }
            writeSec = posSec;
            api.av_frame_unref(frame);
            if (stop) break;
        }
    }

    // 冲掉 swr 里剩余的样本并投进对应的片（不这么做末尾几片会偏小）
    if (!stop) {
        int produced = api.swr_convert(swr, &buffer, kBufferSamples, nullptr, 0);
        while (produced > 0) {
            const int16_t *samples = reinterpret_cast<int16_t *>(buffer);
            stop = feed(samples, produced, writeSec);
            writeSec += double(produced) * sampleStep;
            if (stop) break;
            produced = api.swr_convert(swr, &buffer, kBufferSamples, nullptr, 0);
        }
    }

    api.av_freep(&buffer);
    api.av_frame_free(&frame);
    api.av_packet_free(&packet);
    api.swr_free(&swr);
    api.avcodec_free_context(&codecCtx);
    api.avformat_close_input(&fmt);
    return true;
}
```

## 3. 绘制 —— `src/ui/TimelineWidget.cpp`

```cpp
constexpr int kWaveSlices = 600;    // 需求：可见区间切 600 片，片内用该片高度填满
const QColor kWaveColor(0x8A, 0x8F, 0x98);   // 波形：灰
```

```cpp
void TimelineWidget::setPeaks(AudioPeaks peaks) {
    peaks_ = std::move(peaks);
    update();
}

bool TimelineWidget::peaksCoverView() const {
    return peaks_.covers(viewFrom_, viewTo_);
}

/// [t0, t1) 区间内的最大绝对振幅（0..32767）
int TimelineWidget::peakLevel(double t0, double t1) const {
    if (peaks_.empty() || peaks_.pointsPerSec <= 0.0) return 0;
    const double pps = peaks_.pointsPerSec;
    std::size_t i0 = static_cast<std::size_t>(std::max(0.0, (t0 - peaks_.fromSec) * pps));
    std::size_t i1 = static_cast<std::size_t>(std::max(0.0, (t1 - peaks_.fromSec) * pps));
    if (i1 <= i0) i1 = i0 + 1;
    i0 = std::min(i0, peaks_.size() - 1);
    i1 = std::min(i1, peaks_.size());
    int level = 0;
    for (std::size_t i = i0; i < i1; ++i) {
        level = std::max(level, std::max(std::abs(static_cast<int>(peaks_.min[i])),
                                         std::abs(static_cast<int>(peaks_.max[i]))));
    }
    return level;
}

void TimelineWidget::drawWaveform(QPainter &p, const Layout &l) {
    const int midY = l.waveTop + l.waveH / 2;
    const int halfH = l.waveH / 2 - 1;

    // 峰值数据还没覆盖当前可见区间（刚导入 / 刚缩放平移）：先给占位，
    // 后台算完再刷新 —— 这样长视频不用等波形算完就有画面
    if (!peaksCoverView()) {
        p.setPen(QPen(QColor(0xB0, 0xB0, 0xB0), 1, Qt::DashLine));
        p.drawLine(0, midY, width(), midY);
        p.setPen(palette().color(QPalette::Disabled, QPalette::Text));
        p.drawText(QRect(0, l.waveTop, width(), l.waveH), Qt::AlignCenter,
                   hasAudio_ ? QStringLiteral("波形计算中…") : QStringLiteral("无音轨"));
        return;
    }

    // 可见区间切 600 片：每片算出该片高度，片内用这个高度填满
    const double slice = span() / double(kWaveSlices);
    p.setPen(Qt::NoPen);
    for (int i = 0; i < kWaveSlices; ++i) {
        const double t0 = viewFrom_ + double(i) * slice;
        const int level = peakLevel(t0, t0 + slice);
        if (level <= 0) continue;
        const int h = std::max(1, static_cast<int>(std::lround(double(level) / 32767.0 * halfH)));
        const int x0 = static_cast<int>(std::lround(double(i) * width() / kWaveSlices));
        const int x1 = static_cast<int>(std::lround(double(i + 1) * width() / kWaveSlices));
        p.fillRect(x0, midY - h, std::max(1, x1 - x0), 2 * h, kWaveColor);
    }
    p.setPen(QColor(0xCC, 0xCC, 0xCC));
    p.drawLine(0, midY, width(), midY);
}
```

### 4.2 导入后补做（`MainWindow.cpp`）

```cpp
void MainWindow::startCutBackgroundAssets(int token) {
    if (!cutLoaded_) return;
    auto guard = QPointer<MainWindow>(this);
    const QString path = cutSource_;

    // 1) 关键帧表（只扫包头）—— 吸附要用
    (void)QtConcurrent::run([this, guard, path, token]() {
        const std::vector<double> keys =
            lr::MediaProbe::keyframeTimes(FfmpegApi::instance(), path.toStdString());
        QMetaObject::invokeMethod(this, [this, guard, token, keys]() {
            if (!guard || token != cutToken_ || !timeline_) return;
            cutKeyframes_ = keys;
            timeline_->setKeyframes(keys);
            appendLog(QStringLiteral("关键帧 %1 个").arg(keys.size()), lr::logcolor::kMuted);
        }, Qt::QueuedConnection);
    });

    // 2) 波形：只算当前可见区间
    rebuildCutWaveform(token);
}

void MainWindow::rebuildCutWaveform(int token) {
    if (!cutLoaded_ || !timeline_) return;
    if (!cutInfo_.hasAudio) {
        appendLog(QStringLiteral("该视频没有音轨，不绘制波形。"), lr::logcolor::kMuted);
        return;
    }

    const double from = timeline_->viewFrom();
    const double to = timeline_->viewTo();
    if (to - from <= 1e-6) return;
    const int waveToken = ++cutPeaksToken_;

    auto guard = QPointer<MainWindow>(this);
    const QString path = cutSource_;
    (void)QtConcurrent::run([this, guard, path, token, waveToken, from, to]() {
        lr::AudioPeaks peaks;
        std::string error;
        // 可见区间切 600 片，每片算出该片的波形高度
        const bool ok = lr::AudioPeakBuilder::buildRange(
            FfmpegApi::instance(), path.toStdString(), from, to, 600, peaks, error);
        QMetaObject::invokeMethod(this, [this, guard, token, waveToken, peaks, ok, error]() {
            if (!guard || token != cutToken_ || waveToken != cutPeaksToken_ || !timeline_) return;
            if (!ok || peaks.empty()) {
                if (cutPeaks_.empty()) {
                    appendLog(QStringLiteral("波形生成失败：") + QString::fromStdString(error),
                              lr::logcolor::kMuted);
                }
                return;
            }
            cutPeaks_ = peaks;
            timeline_->setPeaks(peaks);
        }, Qt::QueuedConnection);
    });
}
```

```cpp
void MainWindow::refreshCutTimelineAssets() {
    if (!cutLoaded_ || !timeline_) return;
    const double from = timeline_->viewFrom();
    const double to = timeline_->viewTo();
    const double span = std::max(1e-3, to - from);
    const int token = cutToken_;

    // 缩略图：5 张，取可见区间的 左/1/4/中/3/4/右
    auto guard = QPointer<MainWindow>(this);
    (void)QtConcurrent::run([this, guard, token, from, span]() {
        std::array<QImage, lr::ui::TimelineWidget::kThumbCount> thumbs;
        /* …取帧… */

        }, Qt::QueuedConnection);

    // 波形：可见区间变了，就对新区间重新切 600 片
```

## 6. 可调参数一览

| 参数 | 位置 | 当前值 | 说明 |
|---|---|---|---|
| 切片数 | `TimelineWidget.cpp: kWaveSlices`、`rebuildCutWaveform(…, 600, …)` | 600 | 两处要同步改 |
| 重采样率 | `AudioPeaks.cpp: kOutSampleRate` | 8000 Hz | 峰值只需低频，调高只增耗时 |
| seek 回退 | `AudioPeaks.cpp: back = fromSec - 1.0` | 1.0 s | 太小会让波形左端缺一块 |
| 刷新节流 | `MainWindow::setupTimeline(): assetThrottle_->setInterval(150)` | 150 ms | 拖动跟手 vs 解码次数 |
| 波形层高 | `TimelineWidget.cpp: kWaveHeight` | 56 px | 只影响观感 |
| 波形色 | `TimelineWidget.cpp: kWaveColor` | `#8A8F98` 灰 | 需求：与底色有区别即可 |

**「每片取瞬时采样值」而不是「片内峰值」**的改法：把 `feed` 里那两行
`min/max` 累加换成"只在跨片时记录当前采样值"即可（会出现随机毛刺，视觉上是锯齿状）。

## 7. 踩过的坑（改这块时务必留意）

1. **seek 后必须用 `avcodec_flush_buffers(codecCtx)`**。
   用 `avcodec_send_packet(ctx, nullptr)` 排空是错的：空包是流结束语义，会把解码器推进
   draining 状态，之后所有 `send_packet` 返回 `AVERROR_EOF`（-541478725），
   表现为**波形整段为 0**。这个坑在取帧（`FrameGrabber`）和音频（`AudioPeaks`）两侧各踩一次。
2. **读 `fmt->duration` 前必须先 `avformat_find_stream_info`**，否则 MP4 上常为 0，
   分桶数算成 0，表现为"没有波形"。
3. **seek 要往前多退一点**：音频 seek 只能落到关键位置，直接定位到 `fromSec` 会丢开头一段。
4. 结果回 GUI 线程用 `QMetaObject::invokeMethod`（避免给自定义类型注册元类型），
   并用 `cutToken_` / `cutPeaksToken_` 双重 token 丢弃过期结果。
